# Complete-AI-Research-Course

*    Step 1 (Fraud Ensembles): Combines XGBoost, CatBoost, and DenseNet with an Isolation Forest veto mask to counter extreme data imbalance in credit card fraud detection.
*   Step 2 (Neural ODEs): Processes irregularly-spaced time-series data continuously by integrating ODERNNs with mathematical differential solvers.
*   Step 3 (Temporal SSL): Learns robust time-series features without manual labels by aligning augmented signal views using contrastive InfoNCE loss.
*   Step 4 (DINOv2 & SHAP): Classifies and localizes visual surface defects by combining frozen vision transformer representations with post-hoc SHAP explainers.
*   Step 5 (Concept Bottlenecks): Partitions raw text classifications into human-readable intermediate concept layers to provide complete transparency over decision logic.
*   Step 6 (Bayesian Networks): Models neural weights as probability distributions to compute output variance and entropy, flagging out-of-distribution inputs.
*   Step 7 (Randomized Smoothing): Injects input noise and uses Monte Carlo averaging to guarantee mathematical model robustness against worst-case perturbations.
*   Step 8 (Knowledge Distillation): Trains a lightweight student CNN to replicate a heavy Vision Transformer's complex decisions using soft probability targets.
*   Step 9 (Elastic Weight Consolidation): Mitigates catastrophic forgetting by using the Fisher Information Matrix to identify and protect critical task parameters.
*   Step 10 (LoRA): Reduces trainable parameter footprint by 99% by decomposing dense weight updates into low-rank matrix pairs.
*   Step 11 (Soft Prompt Tuning): Adapts frozen transformer backbones to new tasks by appending trainable virtual token embeddings to input sequences.
*   Step 12 (Mixture of Experts): Decouples capacity from computational cost by dynamically routing tokens to specialized subnetworks using a top-k router.
*   Step 13 (Optimal Transport): Aligns features across shifted domains by minimizing Wasserstein distance using the entropic Sinkhorn-Knopp algorithm.
*   Step 14 (Adaptive GNNs): Aggregates graph neighbor features selectively using dynamic edge attention to achieve built-in explainability.
*   Step 15 (Prototypical Networks): Generalizes instantly to unseen categories by mapping queries to class support-set prototypes in a latent metric space.
*   Step 16 (Beta-VAEs): Disentangles latent representations by penalizing Kullback-Leibler divergence to isolate independent physical properties.
*   Step 17 (Hardware-Aware NAS): Discovers optimal trade-offs between validation accuracy and model parameter size using multi-objective evolutionary search.
